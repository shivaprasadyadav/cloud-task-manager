# Cloud Task Manager

## Project Overview
A Task Management Web Application built using
Python Flask, HTML and CSS.

## Features
- Add new tasks
- View tasks
- Mark tasks as completed
- Delete tasks

## Technologies
- Python
- Flask
- HTML
- CSS
- Git
- GitHub

## Project Structure

cloud-task-manager/
├── app.py
├── requirements.txt
├── templates/
├── static/
├── uploads/
└── README.md

## Installation

1. Clone the repository.
2. Create a virtual environment.
3. Install dependencies:

pip install -r requirements.txt

4. Run the application:

python app.py

5. Open http://127.0.0.1:5000
